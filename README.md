# 📚 我們的專案文件中心

這是一個使用 [Docusaurus](https://docusaurus.io/) 架設的現代化靜態文件網站，專門用來管理與展示我們的專案資訊、設計規範與操作手冊。

## 🚀 如何在本地端（自己的電腦）預覽？

如果你想要修改內容，並在自己的電腦上即時預覽畫面的變化，請按照以下步驟：

1. 透過 VS Code 開啟本專案資料夾。
2. 打開終端機 (Terminal)。
3. 輸入以下指令啟動本地伺服器：

```bash
npm run start

```
